Test Senaryosu
1.Amazon ana sayfasına gidilir ve çerezler kabul edilir.

2.Arama kutusuna "iPhone 15 Pro Max" yazılarak arama yapılır.

3.Arama sonuçlarında belirli bir fiyat filtresi ve renk seçeneği uygulanır.

4.Ürün detayına gidilerek "Satın Alma Seçenekleri" üzerinden ürün sepete eklenir.

5.Sepet doğrulandıktan sonra ödeme (checkout) adımına geçilir.

6.Giriş yapma sayfasının doğrulanmasıyla süreç tamamlanır.
